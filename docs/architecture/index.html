Methodology
V2 requires complete NWS/GFS/IFS forecasts. Switchable entry rules cover model consensus, peak timing, weather changes and recent trends. Seven-variant offline ablations use separate run directories. A separate recent-history benchmark validates IEM MOS and raw NWS CLI archives, freezes earlier calibration, writes predictions before reading labels, and reports weather accuracy only. Assumed historical availability does not unlock live RAG. Cloud benchmark billing/auth/rate failures stop subsequent requests; uncertain budget reservations remain. Completed historical runs feed a shared-case accuracy graph with coverage and day-block uncertainty. Supplemental US display-price histories and venue settlements have no historical quantities and cannot establish fills. A separate contract-return harness selects exact bins without outcome ranking, retrieves minute-level price windows, commits cloud forecasts, then checks settlements and evaluates hypothetical full-fill scenarios with fees, delayed cash release, model costs and overhead. PolySwarm uses its market blend in this harness. Quantities and fills remain unverified. See ../RECENT-HISTORY.md for results and limitations. Original sample demos omit the new protocol. Previous-weeks archive jobs serialize one station and 1-4 weeks of completed standard days, retrieving NOAA MOS vintages and separate NWS CLI outcomes. This is not Apple history and never backdates live RAG. Private-model JSONL intake records local receipt and returns at most three exact-contract, unexpired predictions when enabled. No private outputs are supplied yet. Reviewed article hypotheses use the existing bounded strategy-card path. A separate 23-policy cost comparison freezes development selection before scoring later dates; cached calls model possible savings, not refunded spend. Daily RAG collection is a separate Sol / low scheduled task. Apple Weather / NWS is currently a separate comparison study. It is not wired into strategy forecasts. Cloud access and phone setup remain configuration prerequisites; these figures do not establish live inference, fills or profitability.
